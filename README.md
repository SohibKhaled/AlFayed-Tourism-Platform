# الفايد للسياحة — Al-Fayed Tourism (`Powered by Global EIS`)

منصة حجز سياحي فورية (**فنادق + طيران + تجهيز تأشيرات + باكيدج مزدوج**) تدعم البث اللحظي للأسعار والتوافر وإدارة هوامش الربح دون مطالبة العميل بإنشاء حساب أو تسجيل دخول.

## المزايا الرئيسية (Key Features)

- **تجربة مزدوجة التصميم (`Dual Experience`)**:
  - **✨ ستوديو الرحلة التفاعلي (`Al-Fayed Bespoke Journey Studio`)**: 4 محطات متسلسلة لاختيار المزاج والوجهة من 10 مدن عالمية، تقويم أسعار موسمي تفاعلي لشهرين، تحديد طابع الرفقة ومزاج المقعد، ونموذج جواز حي مع بطاقة صعود (`Live Boarding Pass`) تتحدث مباشرة مع كل حرف وختم تأكيد VIP.
  - **🧭 الكتالوج الكامل والفلاتر (`Full Explorer`)**: استعراض جميع الفنادق (15 فندقاً بـ 3 فئات غرف) والرحلات (16 رحلة بـ 3 فئات تذاكر) مع فلاتر متقدمة ومقارنة جنباً إلى جنب.
- **حجز مزدوج ذري في ثانية واحدة (`Atomic Dual-Lock Bundle`)**: تثبيت وتأكيد الفندق + الطيران معاً في معاملة واحدة بخصم باكدج تلقائي وحماية كاملة من البيع المزدوج أو تغيّر السعر أثناء الدفع.
- **بدون تسجيل دخول (`Zero-Login Guest Checkout`)**: حجز مباشر بالبيانات الأساسية وإصدار مرجع موثق فوري (`AFY-...` أو `AFY-PKG-...`).
- **تحديث لحظي بالبث المباشر (`SSE Real-Time Feed`)**: تحديث فوري للأسعار والتوافر والإخفاء التلقائي للعروض المنتهية مع نبض سوق تلقائي.
- **مؤشر ذكاء التأشيرات (`Visa Readiness & Desk Upsell`)**: عرض متطلبات التأشيرة حسب الجواز (`EG`, `SA`, `AE`, `JO`) مع خيار إضافة تجهيز ملف التأشيرة.
- **لوحة إدارة الهامش والأسعار (`Admin Margin Studio`)**: تحكم لحظي في هامش الربح (عام / فئة / مزود API) ونسبة خصم الباكيدج مع محاكاة تغيّر الأسعار والنفاد.
- **واجهة ثنائية اللغة ومتعددة العملات**: دعم كامل للعربية (`RTL`) والإنجليزية (`LTR`) والعملات (`EGP`, `SAR`, `AED`, `USD`).

## التشغيل المحلي (Quick Start)

```bash
npm install
npm start
```

افتح المتصفح على `http://localhost:3000`.

## الاختبارات (Tests)

```bash
npm test
```

## الهيكل العام للمشروع

- `server/index.js` — خادم Express + مسارات API + بث Server-Sent Events (`/api/stream`)
- `server/engine.js` — محرك التسعير والتثبيت الذري والقفل المزدوج وإدارة الحجوزات
- `server/seed.js` — بيانات الوجهات والفنادق والرحلات وقواعد التأشيرات الأولية
- `public/js/journey.js` — واجهة ستوديو الرحلة التفاعلي ذات الأربع محطات والـ Live Boarding Pass
- `public/js/app.js` — منطق العرض الرئيسي ومبدّل التجربة والكتالوج وإدارة الحالة اللحظية
- `public/js/checkout.js` / `public/js/admin.js` / `public/js/i18n.js` — وحدات الدفع، الإدارة، والترجمة
- `tests/` — اختبارات المحرك وتدفقات API والـ Bundle الذري
